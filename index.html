📓
Vexon IT Notion Workspace
Free at notion.so — works on iPhone, iPad, and PC. This is your back office: client notes, prospect tracking, invoices, goals.
Setup Steps
1
Create Your Free Account
Go to notion.so → Sign up free with your email. Download the app on your iPhone and iPad. This syncs everything automatically.
2
Create a "Vexon IT" Workspace Page
Click + New Page → Title it 🖥️ Vexon IT Operations. This is your home base. Everything lives inside here.
3
Create These 6 Sub-Pages
Inside your Vexon IT page, create one page for each of these:
📋 Prospect Tracker 💼 Active Clients 🧾 Invoices & Payments 🛠️ Job Notes 🌾 Ranch Goal Tracker 📚 Reference Guides
4
Set Up Prospect Tracker as a Database
Open Prospect Tracker → Type /table → Create inline database. Add these columns:
Business Name → Title (default) Owner Name → Text Phone → Phone City → Select (Pharr/Harlingen/Brownsville) Status → Select (Cold/Contacted/Interested/Client/No) Date Visited → Date Follow Up Date → Date Monthly Rate → Number Notes → Text
Now every prospect you visit gets a row. Filter by Status to see who to follow up with today.
5
Set Up Active Clients Database
Open Active Clients → Type /table → Add these columns:
Business Name → Title Contact Name → Text Phone → Phone Monthly Rate → Number Start Date → Date Invoice Day → Select (1st/15th) Paid This Month → Checkbox Notes → Text Contract Signed → Checkbox
6
Set Up Ranch Goal Tracker
Open Ranch Goal Tracker → Use this simple layout:
🎯 GOAL: $25,000 land down payment 💰 Saved so far: $______ 📅 Monthly saving: $______ 📆 On track for: ______ MILESTONES: ☐ $500 — Open Ally savings account ☐ $1,000 — Visit FSA office ☐ $3,000 — Emergency fund done ☐ $5,000 — Start land search ☐ $8,000 — Credit score 620+ ☐ $25,000 — DOWN PAYMENT READY 🏡
Update this every payday. Watching it grow is the motivation to keep going.
7
Daily Workflow in Notion
Morning: Check Follow Up Date column — who do you need to text today?

After a job: Add notes to Job Notes page — what you fixed, passwords, what they need next.

1st of month: Check Paid This Month checkboxes — who hasn't paid?

Payday: Update Ranch Goal Tracker savings amount.
